# Knit Hacky avatars

Fallback avatars for people without a photo: the knit Hacky mascot as a head-and-shoulders
bust, personalized by the person's saved `hackyStyle`. 384x384 webp, transparent background,
framed for a circular crop (24-64 px on screen).

Naming: `knit-{color}-{flair}.webp`, using the ids from `react/src/mascot-data.js`.

- `color` sets the cape: `original` (knit orange), `berry` (purple), `mint`, `sunset` (coral red),
  `rose` (pink), `ice` (light blue). The head, body and LED face are the same for every color.
- `flair` sets the glowing LED face: `none` (rounded-square eyes, smile), `stars` (happy `^ ^`
  eyes, big smile), `hearts` (heart eyes, smile).

Generated by `generate.py` from `../webp/hacky-knit.webp`: it covers the stitched face with navy
knit texture, paints the LED face, recolors the cape (luminance-preserving), adds the brass antenna
and gold ball, then crops and downsamples. It needs numpy and ffmpeg with libwebp (no PIL).

```sh
python3 generate.py                 # rewrite all 18 files
python3 generate.py --sheets /tmp/x # also write contact sheets (full size, 64 px, 40 px)
```
